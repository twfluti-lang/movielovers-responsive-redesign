## MovieLovers – From XHTML to Responsive HTML5
**Project Overview**: A technical modernization of a movie club website, focusing on responsive design, accessibility, and structured information architecture. This was an assignment for the course Introduction to Web Development (DA106A) at Malmö University.


### Technical Transformation
The primary focus of this project was a complete overhaul of the site's technical foundation:
- **Migration to HTML5**: The original site used XHTML. It has been migrated to HTML5 to ensure semantic structure and modern web standards.
- **Separation of Concerns**: All styling has been moved to an external CSS file (`style.css`), making the code more organized and maintainable.
- **Bootstrap 5.3 Integration**: Implemented a `navbar fixed-top` using Bootstrap to provide a consistent and professional navigation experience across all pages.

### Usability & Accessibility (UX)
As an Information Architect student, I prioritized the user experience through several key improvements:
- **Responsive Design**: The site is now fully optimized for mobile devices, ensuring content is accessible regardless of screen size.
- **Readability & Contrast**: Improved color harmony and contrast to enhance the experience, particularly for users with visual impairments.
- **Information Architecture**: Implemented a hierarchical dropdown menu to categorize movies (e.g., Star Wars, Inception), reducing cognitive load for the user.

## MovieLovers - Från XHTML till Responsiv HTML5
**Projektstatus**: Slutförd inlämningsuppgift inom Introduktion till webbutveckling (DA106A) vid Malmö Universitet. 
Detta projekt fokuserar på att transformera en föråldrad webbplats till en modern, användarvänlig och tekniskt strukturerad plattform för filmentusiaster.


### Teknisk Transformation

Den största kritiska förbättringen i projektet var skiftet i den tekniska arkitekturen:
- **Migration till HTML5**: Den ursprungliga webbplatsen använde XHTML. Genom att byta till HTML5 har koden blivit mer semantisk och framtidssäkrad.
- **Separation av kod**: Jag har brutit ut all design till en extern CSS-fil (`style.css`). Detta gör projektet mer organiserat och underlättar framtida uppdateringar, till exempel via media queries.
- **Bootstrap-integration**: För att hantera navigering på ett professionellt sätt används Bootstrap 5.3:s `navbar fixed-top`, vilket ger en enhetlig upplevelse på alla undersidor.


### Användbarhet & Tillgänglighet (UX) 
Som informationsarkitekt är användarens upplevelse central. Följande förbättringar har implementerats:

- **Responsiv Design**: Webbplatsen är nu optimerad för mobila enheter, vilket är avgörande då dagens användare förväntar sig tillgänglighet oavsett skärmstorlek.
- **Läsbarhet & Kontrast**: Jag har förbättrat färgkontraster och harmoni för att öka tillgängligheten, särskilt för användare med synnedsättningar.
- **Navigeringsstruktur**: En hierarkisk dropdown-meny har skapats för att organisera filmerna (t.ex. Star Wars och Inception), vilket minskar kognitiv belastning och gör informationen lättare att hitta.


### Projektstruktur

- `index1.html` – Startsida med introduktion till filmklubben.
- `index2.html` till `index5.html` – Informationssidor om specifika filmer med betyg och handling.
- `index7.html` – Kontaktformulär för användarinteraktion.
- `style.css` – Centraliserad design och layout.
- `reset.css` – Säkerställer konsekvent rendering i olika webbläsare.


### Lärdomar & Akademisk Integritet

Genom detta projekt har jag fördjupat min förståelse för vikten av att kombinera teknisk struktur med användarbehov. All filminformation (handling, skådespelare, regissör) är korrekt källhänvisad till externa tjänster som [Filmtipset.se](https://www.filmtipset.se/) för att bibehålla hög trovärdighet.
